# Korrektur von Schülerlösungen (Kurzfassung ISB-Handreichung 2.2)

Dient dazu, Bewertungshinweise in Musterlösungen zu formulieren oder eine Schülerlösung zu bepunkten.

## Grundprinzip

- Max. Punkte je (Teil-)Aufgabe dürfen nicht überschritten werden; nie unter 0 P je Teilaufgabe (keine Maluspunkte).
- Buchungssatz: Konto (Nummer + Kürzel) + Betrag = ein „Block“ = 1 P. Fehler in Konto **oder** Betrag → Block 0 P (Unterstreichen).
- Teilergebnisse: falsch → kein Punkt. Folgefehler: richtiger Lösungsweg auf falschem Vorwert gibt die Folgepunkte, wenn sich die Teilaufgabe direkt aus der vorherigen ergibt (Kennzeichen „FF“).
- Unabhängig lösbare Teilaufgaben → kein Folgefehler.

## Fehlerarten

| Fall | Behandlung |
|---|---|
| Geringfügige Abweichung (falsche Kontonummer bei richtigem Kürzel, fehlendes/abweichendes Kürzel, Übertragungs- oder Rundungsfehler, Nachkommastelle) | ½ P für den betroffenen Block statt 1 P; Lehrkraft entscheidet im Kontext |
| Konto fehlt (z. B. VORST vergessen) | P für fehlenden Block entfällt; abweichende Beträge der übrigen Konten = Folgefehler |
| Teil einer Buchung fehlt (z. B. AG-Anteil SV) | Punkte der fehlenden Buchung entfallen |
| Mehr Buchungen/Konten als gefordert | −1 P je nicht geforderter Buchungssatz bzw. überflüssigem Konto, gekennzeichnet („− 1 P: nicht gefordert“); Fehler im überflüssigen Satz werden nicht bewertet, nur markiert. Ausnahme: korrekte zeitliche Zuordnung (Datum angegeben) oder Satz eindeutig vom geforderten trennbar → kein Abzug |
| Drehfehler (Soll/Haben vertauscht) | 0 P für den Buchungssatz; Doppelpfeil „↔“ gilt nicht. Formale Vorgabe muss vorab im Unterricht bekannt sein |
| Geschäftsfall nicht erfasst | „NE“, 0 P für die Teilaufgabe |
| Keine Beträge im Buchungssatz | nur Punkte für richtige Konten (Teillösung) |
| Beträge falsch zugeordnet (z. B. Auszahlung/Kreditsumme) | betroffene Blöcke 0 P; kein gesonderter Doppik-Abzug, Hinweis „Doppik“ möglich |
| Nebenrechnung fehlt, Beträge im Satz richtig | Punkt für die Nebenrechnung entfällt |
| Nebenrechnung fehlt, Beträge falsch | Punkte für Ermittlung und für die betroffenen Konten entfallen |
| Alternativer richtiger Lösungsweg | volle Punkte |
| Brutto-Netto (Jgst. 7) | Extrapunkt für die Ermittlung des Nettobetrags; ab Jgst. 8 nicht |

## Kennzeichnung

✓ richtig, ✓FF Folgefehler richtig, unterstrichen = falscher Betrag/Konto, NE, „− 1 P: nicht gefordert“, Punktzahl je Aufgabe am Rand (z. B. `3P`, `1,5 P`), halbe Punkte nur bei geringfügigen Fehlern.

## Textaufgaben

Punkteregeln je Operator: `operatoren_punkte.md`. Regeln zu überzähligen Nennungen oder Fallbezug stehen nicht in der Handreichung – Festlegung durch die Lehrkraft, vorab bekannt geben.

## Buchungslesen (2.2.13)

Geschäftsfall so formulieren, dass er sich rückwärts wieder zum selben Buchungssatz führen lässt; konkretes, sinnvolles Beispiel wird begrüßt, aber nicht zwingend gefordert. Lösungsvorschlag mit „z. B.:“ und Haken auf Geschäftsart + Gegenstand + Betrag.

## Hinweis zur Verlässlichkeit

Die Tabelle ist eine Verdichtung der Handreichung; bei Zweifelsfällen hat die pädagogische Entscheidung der Lehrkraft Vorrang.
